# The Himalayan Horizon

Uttarakhand village travel, homestays, workations, trip planning and shared cabs.

The website and Android PWA run from the same Next.js App Router application in **web/**. Routes live in web/app, reusable UI in web/components, and static images and icons in web/public. Supabase migrations and database tests live in supabase/migrations and tests/db.

See [setup](docs/SETUP.md) for local development and deployment and [application notes](web/README.md) for the feature inventory.
